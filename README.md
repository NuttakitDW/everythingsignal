# 📘 EverythingSignal — Decentralized Quant Model Marketplace

**EverythingSignal** is a platform that allows creators to **build, test, and publish quantitative trading models** using a safe, original expression language.  
Buyers can explore model performance, review backtest results, and purchase full access to model logic.

All model artifacts — **code, results, metadata, and versions** — are stored on **Walrus**, providing **immutable, verifiable, and decentralized storage**.

---

## 🚀 Why EverythingSignal?

Trading models are often locked inside hedge funds or private research groups.  
EverythingSignal opens that world by letting independent quants:

- Build and test models  
- Share performance publicly  
- Publish models to a marketplace  
- Generate income from buyers  
- Maintain ownership with verifiable proofs stored on Walrus  

Buyers get transparent, performance-driven access to high-quality signals.

---

## 🧠 Key Features

### 🔹 Custom Expression Language (ESL)
A lightweight, safe, original mathematical expression language for writing quant signals.  
Not based on any proprietary DSL.

---

### 🔹 Built-in Backtesting Engine
Users can test their model on historical data with metrics like:

- PnL  
- Sharpe  
- Drawdown  
- Turnover  

---

### 🔹 Publish Models to Marketplace
Creators can list models with:

- Description  
- Performance charts  
- Metadata  
- Version history  

Buyers see performance **but cannot see model code until purchase**.

---

### 🔹 Secure Model Reveal
After purchase:

- Buyers unlock model logic  
- Model files are fetched from Walrus  
- Creators remain protected with immutable storage and versioning

---

### 🔹 Walrus-Powered Storage
Walrus is used to store:

- Model files  
- Backtest results  
- Metadata  
- Versioned releases  

This ensures **integrity, permanence, and verifiability**.
